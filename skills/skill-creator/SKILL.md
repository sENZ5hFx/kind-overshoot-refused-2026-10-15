# skill-creator

A class without a kill rule is a slogan. A refusal without the arithmetic is also a slogan.

Write:

- one-sentence remainder
- the kill that fired, with the numbers
- explicit "do not re-issue" list
- the leftover, still unminted

Do not mint the leftover in the same session that proved it is not yet a rectangle.

A Wiley index line is not the correction. If the correction text was not extracted, say so.
